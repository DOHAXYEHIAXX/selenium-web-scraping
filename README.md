# Selenium Web Scraping — Data Engineer Jobs

Python Advanced — Lab 1.

The assignment objective is to use Selenium with Python to scrape real job listings from Naukrigulf, collect Data Engineer listings from the first three pages of search results, and export the extracted data to CSV. The required fields are Job Title, Company Name, Job Location, Required Experience, and Full Job Description.

## Structure

```text
selenium-web-scraping/
├── scraper.py
├── requirements.txt
├── output/
│   └── data_engineer_jobs.csv   # generated by the script
└── README.md
```

## Run

```bash
pip install -r requirements.txt
python scraper.py
```

The script uses a Chrome/Chromium WebDriver managed by Selenium Manager and navigates through the first three result pages.

> Website layouts can change. If Naukrigulf changes its HTML structure, the CSS selectors in `scraper.py` may need to be updated.
